# 2026-07-10 工作交接 — 视觉检测系统重构

## 概述

将仪表柜面检测从 OpenCV 模板匹配替换为 YOLOv8 深度学习，拆分为两条独立管线：

| 管线          | 相机                                | 用途                    | 模型                                                                    |    推理速度    |
| ------------- | ----------------------------------- | ----------------------- | ----------------------------------------------------------------------- | :------------: |
| RTSP 前置广角 | Lite3 内置相机 (192.168.1.120:8554) | 字母 A/B/C/D + 仪表颜色 | `InstanceSegmentation/projects/gauge/model/best.pt` (mAP50=0.973)     | **33ms** |
| D455 深度相机 | Intel RealSense USB                 | 红绿物块 + 障碍物       | `src/cv/depth_detector/projects/combined/model/best.pt` (mAP50=0.964) |      待测      |

## 日常使用

### 1. RTSP 实时检测 (字母+仪表)

```bash
cd ~/quadruped-robot-competition
LD_PRELOAD=/lib/aarch64-linux-gnu/libgomp.so.1 \
  python3 src/cv/gauge_detector/live_detect.py
```

| 按键 | 功能                                                  |
| ---- | ----------------------------------------------------- |
| 空格 | 保存当前帧 →`InstanceSegmentation/debug_captures/` |
| Q    | 退出                                                  |

> **⚠️ 识别前必须让狗在距柜面 30cm 处停稳，相机正对，画面无抖动。** 距离/角度不对会导致字母识别失败。

### 2. 程序内调用

```python
from cv.gauge_detector import GaugeDetector

det = GaugeDetector()
result = det.detect(frame)           # BGR numpy array

letter = result.best_letter          # LetterDetection(letter='C', confidence=0.95)
gauge  = result.best_gauge           # GaugeDetection(color='green', confidence=0.88)

# 兼容旧 API (Inspector 内部已使用)
from whz.inspection import Inspector, InspectionResult
from whz.audio_player import AudioPlayer
from whz.paths import default_audio_dir

audio = AudioPlayer(default_audio_dir())
inspector = Inspector(det, audio)
result = inspector.inspect_once(frame)   # 单帧
result = inspector.inspect_frames(frames) # 多帧投票
```

### 3. ROS2 服务调用 (已更新)

```bash
# 启动 RTSP 版
LD_PRELOAD=/lib/aarch64-linux-gnu/libgomp.so.1 \
  python3 src/nodes/perception/whz_rtsp_inspect.py

# 调用
ros2 service call /whz/inspect std_srvs/srv/Trigger
```

## Docker (cuVSLAM + YOLO)

### 新镜像: `cuvslam_yolo:humble` (17.3GB)

基于 `isaac_ros_cuvslam_runtime:humble-rs`，额外安装了 `ultralytics==8.2.103` + `matplotlib` + `seaborn` + `torchvision`。

**cuVSLAM 功能不受影响**——只新增了 Python 包，ROS2/C++ 核心未改动。

### 启动方式

```bash

bash scripts/start_cuvslam_rviz_gui.sh

# 带 YOLO 的 cuVSLAM (用新镜像 + 开 RGB)
IMAGE=cuvslam_yolo:humble ENABLE_COLOR=1 bash scripts/start_cuvslam_rviz_gui.sh
```

### 🟢 后续优化：完善视觉模型 & 收集数据集

#### 什么时候需要收集新数据

现场实测时遇到以下情况，按空格保存误检/漏检帧：

- 字母识别错误（C 判成 D 等）
- 仪表颜色判错（green 判成 yellow 等）
- 完全没检出（应该检出但 returned none）
- 误检（不该检出的地方画了框）

#### 采集流程

**步骤 1：启动实时检测脚本**

```bash
cd ~/quadruped-robot-competition
LD_PRELOAD=/lib/aarch64-linux-gnu/libgomp.so.1 \
  python3 src/cv/gauge_detector/live_detect.py
```

| 按键 | 功能 |
|------|------|
| **空格** | 截图 → 保存到 `InstanceSegmentation/debug_captures/debug_xxx.jpg` |
| **Q** | 退出 |

屏幕左上角实时显示 `saved:N` 计数。**对着有问题的情况按空格**，把误检/漏检的画面存下来。

**步骤 2：拷贝到 Windows 标注**


**步骤 3：用 LabelMe 标注**

用 [LabelMe](https://github.com/labelmeai/labelme) 打开图片，矩形框标注：
- 字母：标签填 `A` / `B` / `C` / `D`
- 仪表颜色：标签填 `green` / `red` / `yellow`
- 保存为 JSON（和 JPG 放同一目录 `InstanceSegmentation/gauge_dataset/`）

**步骤 4：重建数据集 + 重新训练**

